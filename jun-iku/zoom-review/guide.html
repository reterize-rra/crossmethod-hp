オンライン予約とZoomの使い方

主催者がZoomを連携する

JUN-IKUにログインし、カレンダー下部の「オンライン予約」からZoom連携を開きます。Zoomの画面で会議を主催するアカウントを確認して許可し、JUN-IKUに戻って連携状態を確認してください。

予約リンクを送る

  1. 会議名と所要時間（30・45・60分）を決めます。
  2. 予定を登録するカレンダーとタブを選びます。共有カレンダーでは、候補に表示された担当者から主催者を指定します。予約相手に表示する担当者名も入力できます。
  3. 相手に提示したい空き日時を選び、予約リンクを作成して共有します。相手が日時を選んで確定すると、主催者のZoomに会議が作成されます。

予約リンクを受け取った方へ

希望日時を選び、氏名とメールアドレスを入力して予約を確定してください。会社名は任意です。参加リンクは入力したメールアドレスに届きます。JUN-IKUをご利用の方は、同じメールアドレスのアカウントでログインし、マイカレンダーへの追加を選べます。

日時を変える・キャンセルする

主催者がJUN-IKUのカレンダーで予約を開きます。日時を変更するとZoom会議の時刻が更新され、予約者に変更メールが届きます。キャンセルするとZoom会議と双方の登録済みカレンダーから予定が削除され、予約者にキャンセルメールが届きます。

連携を解除する

取り消したい会議がある場合は先にカレンダーからキャンセルしてください。その後、オンライン予約のZoom連携画面で「Zoom連携を解除」を選びます。

困ったときは

主催予定のZoomアカウントで許可したか、予約時に入力したメールアドレスと迷惑メールフォルダーをご確認ください。お問い合わせの際は操作した日時と画面名をお知らせください。

Zoom reviewer walkthrough

  1. Open the review booking calendar and sign in using the JUN-IKU test credentials supplied privately. Select “Zoomと連携する” and authorize your own Zoom account. Return to the booking calendar and refresh its status.
  2. Enter a meeting name, select the duration and at least two available times, then create a booking link. Open the guest link in a separate browser tab. Choose a time and confirm. The isolated review page displays the Zoom join link on screen.
  3. On the host page, refresh the status, select a different time and confirm the change. Then cancel the booking. Refresh the guest page to see the cancellation.
  4. After cancelling, select “Zoom連携を解除” on the host page and confirm. Refresh the status to verify that the option to connect is shown again.
